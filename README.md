# Full-Stack Roadmap

My personal full-stack engineering learning plan — 13 stages (14 with
the languages addition), from HTML/CSS foundations to production-style
architecture. Adapted from roadmap.sh/full-stack, sequenced 2026-08-01.

**The plan lives in [`ROADMAP.md`](ROADMAP.md).**

## What this repo is

A learning roadmap, not a shipped product. The whole point is genuine
independent understanding, not AI-assisted output. Each stage ends with
a real, working project before moving on — and the projects get
progressively larger and more production-like.

## Contents

- `ROADMAP.md` — the full staged plan
- `CLAUDE.md` — project instructions for Claude sessions here
- `personal-site/` — the Stage 1 deliverable (my contact page)
- `.claude/skills/mentor-mode/SKILL.md` — an optional `/mentor-mode`
  skill that runs strict review sessions on this material when invoked
